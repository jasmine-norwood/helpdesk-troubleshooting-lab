# INC-012 — Active Directory User Administration

## Scenario

A new employee requires a corporate domain account and appropriate access to organizational resources.

## Objective

Configure an Active Directory lab environment and perform common help-desk user administration tasks.

## Environment

- Oracle VirtualBox
- Windows Server
- Active Directory Domain Services
- Windows 11 Pro workstation
- Windows PowerShell

## Planned Tasks

1. Deploy a Windows Server virtual machine.
2. Configure the server hostname and network settings.
3. Install Active Directory Domain Services.
4. Promote the server to a domain controller.
5. Create an Active Directory domain.
6. Create an organizational unit.
7. Provision a domain user.
8. Create and manage security group membership.
9. Perform a user password reset.
10. Verify the user's Active Directory configuration.
